VIGER MONEY — СТАРТ
==================

БЫСТРЫЙ ЗАПУСК НА WINDOWS
1. Распакуй архив в отдельную папку.
2. Дважды нажми «Запустить VIGER MONEY.bat».
3. Откроется http://127.0.0.1:8000/.
4. Не закрывай окно сервера, пока пользуешься локальной версией.

Если Python не установлен:
- установи Python 3 с python.org (при установке включи Add Python to PATH),
- либо открой терминал в папке приложения и выполни: python -m http.server 8000
- затем открой http://127.0.0.1:8000/.

ПЕРВАЯ НАСТРОЙКА
1. Открой «Указать баланс» или «Кошельки» → редактировать «Наличные».
2. Впиши реальную сумму, которая есть сейчас. Начальный баланс не считается доходом.
3. Получил деньги — +50000; потратил — -10000 школа; затем Enter.
4. Регулярно сохраняй резервную копию в «Настройки» → «Экспортировать резервную копию».

ПРИМЕРЫ
+50000                     записать приход 50 000 сум
-10000 школа               записать расход 10 000 сум
потратил 10 тысяч на дорогу  распознать расход и категорию «Транспорт»
получил 50к                 распознать приход 50 000 сум
25000 + 15000              посчитать выражение и открыть форму сохранения

ВАЖНО
- Локальная версия хранит данные в браузере этого устройства.
- Чтобы открыть тот же баланс на телефоне, опубликуй папку на HTTPS-хостинге.
- Для синхронизации телефона и ПК настрой свой Supabase-проект по README.md и supabase-schema.sql.
- Никогда не вставляй Supabase service_role key в клиентское приложение.
- Прежде чем подключать уже заполненные данные с двух устройств, сохрани резервные копии и проверь названия кошельков.


VIGER MONEY 2.0
---------------
This update adds a Money Forecast screen and a phone-first bottom bar. Export a JSON backup from your current version first. Then deploy the updated folder to the exact same website origin you already use; this keeps IndexedDB/localStorage under the same browser origin. Do not clear browser site data. After upload, reload the app; if installed as a PWA, close and reopen it once the update has been fetched.

Forecast: choose a date or 7 / 30 / 90 / 180 days. The app uses recent income/expense records, ignores internal transfers, detects only consistent repeated transactions, and shows cautious, realistic and optimistic estimates. Forecasts are estimates, not guarantees.
